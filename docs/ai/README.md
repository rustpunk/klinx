# AI Onboarding Documentation

This directory is durable onboarding memory for future AI coding agents and human contributors working in Klinx.

Klinx is a Rust 2024 workspace for a Dioxus 0.7 desktop IDE that authors Clinker YAML pipeline configurations. The docs here are evidence-backed from repository files, CI config, source modules, tests, examples, and read-only subsystem exploration performed on 2026-06-15.

Root [../../AGENTS.md](../../AGENTS.md) routes each task to the docs it needs; [00_READ_THIS_FIRST.md](00_READ_THIS_FIRST.md) explains the evidence labels and which doc to update when the system changes. Update [AI_CHANGELOG.md](AI_CHANGELOG.md) when an architecture fact changes.

Root [../../AGENTS.md](../../AGENTS.md) is intentionally concise for automatic agent loading. The detailed reasoning and evidence live here.
